# 확장 계획 2 · M7 ~ M11 (설계 2026-11-06)

A · B · C · M5 · M6 설계는 [ROADMAP.md](../ROADMAP.md)의 "확장 계획" 절. 여기는 그 뒤에 이어지는 M7 ~ M11.
묶음은 git worktree에서 동시에 구현하고 stage2에 합친다. 구현한 행은 "구현"으로 표시하고, 설계와 달라진 점을 그 행에 적는다.
숫자는 실테스트 전 초안이다. 조정할 만한 값은 `config/sanupcraft.json`(SanupcraftConfig)으로 뺀다.

## M7 · 보관 · 제작 편의
| # | 추가 | 설계 | 단계 |
|---|---|---|---|
| S1 | 저장 서랍 | 한 종류 대량 저장. 철 서랍 32더미, 강철 서랍 128더미. 앞면 우클릭 = 손의 것 넣기 (빨리 두 번 = 인벤토리의 같은 것 전부), 좌클릭 = 하나, 웅크리고 좌클릭 = 한 더미 꺼내기. 앞면에 아이템 · 개수 표시(블록 엔티티 렌더러). 깔때기 · 벨트 입출력. 서랍 업그레이드: 용량 ×2 (최대 2개), 넘침 버림 | 강철 |
| S2 | 창고 네트워크 | 창고 관(케이블)으로 상자 · 서랍 · 탱크 · 모든 `Container` 블록을 잇는다. 창고 단말(블록): 이어진 보관함 전체를 한 화면(검색 · 정렬 · 페이지)으로. 넣으면 같은 아이템 있는 곳 → 빈 곳 순. 단말은 증기 틱당 1 (없으면 안 열림) | 강화 기계 틀 |
| S3 | 제작 단말 | 창고 단말 + 3x3 제작 칸. 재료를 네트워크에서 끌어 만든다. JEI 레시피 옮기기(+ 버튼) | S2 다음 |
| S4 | 자동 제작대 | 견본 3x3로 레시피 기억. 재료 9칸(깔때기 · 벨트 · 네트워크)이 차면 만들어 결과 칸으로. 증기로 돎 (1회 증기 20) | 강화 기계 틀 |
| S5 | 재고 유지기 | 네트워크에 붙여 "아이템 X를 N개 유지" (견본 + 숫자). 모자라면 옆 자동 제작대 · 기계에 재료를 보내 만들게 한다 | 파수꾼의 심장 |
| S6 | 휴대 단말 | 들고 우클릭으로 창고 단말을 연다 (단말에 우클릭으로 연결). 기본은 같은 차원 64칸 안, 셜커 껍데기판은 어느 차원에서나 | 엔드 |

잠금: 단말 · 휴대 단말은 엔더 운반기와 같은 주인 잠금 (M10 팀이 생기면 팀도).

## M8 · 산업 규모
| # | 추가 | 설계 |
|---|---|---|
| I1 | 대형 보일러 (다중 블록) | 3x3 바닥 · 높이 4의 강철 외벽(대형 보일러 외벽 블록), 안은 비우고, 앞면 가운데에 대형 보일러 제어기. 모양이 맞으면 보일러 6대 몫(틱당 증기 = 보일러 6배), 연료 · 물 칸이 크다. 모양이 깨지면 멈추고 어디가 틀렸는지 알려 줌 |
| I2 | 용광로 탑 (다중 블록) | 3x3 · 높이 3 내열 벽돌 외벽 + 제어기. 고압 증기로만. 화로 · 합금로 레시피를 한 번에 8개 처리 |
| I3 | 광석 3 · 4배 | 세척기(물을 탱크 · 펌프에서): 원석 → 정제 가루 3 (+희귀 가루 10%). 고압 정련기(고압 증기): 원석 → 정제 가루 4. 정제 가루 → 화로에서 주괴 |
| I4 | 렌치 · 면 설정 | 렌치: 블록 우클릭 = 돌리기, 웅크리고 우클릭 = 모드 기계를 바로 아이템으로(내용물 보존). 기계 면 설정: 면마다 넣기 / 빼기 / 막기 (렌치로 면을 눌러 바꿈) |
| I5 | 증기 기관차 · 화물 열차 | 레일 위 기관차(증기 통 칸 또는 석탄 칸)가 뒤에 연결된 화물칸을 끈다. 화물칸 27칸. 하역 · 적재 역(레일 옆 블록): 지나가는 화물칸과 아이템을 주고받음 |
