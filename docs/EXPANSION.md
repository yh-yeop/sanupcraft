# 확장 계획 2 · M7 ~ M11 (설계 2026-11-06)

A · B · C · M5 · M6 설계는 [ROADMAP.md](../ROADMAP.md)의 "확장 계획" 절. 여기는 그 뒤에 이어지는 M7 ~ M11.
묶음은 git worktree에서 동시에 구현하고 stage2에 합친다. 구현한 행은 "구현"으로 표시하고, 설계와 달라진 점을 그 행에 적는다.
숫자는 실테스트 전 초안이다. 조정할 만한 값은 `config/sanupcraft.json`(SanupcraftConfig)으로 뺀다.

## M8 · 산업 규모
| # | 추가 | 설계 |
|---|---|---|
| I1 | 대형 보일러 (다중 블록) · **구현** | 3x3 바닥 · 높이 4. 제어기(대형 보일러 제어기, 보는 쪽 = 앞)는 앞면 가운데 **맨 아랫줄**, 가운데 기둥의 2 · 3층(제어기에서 위 1 · 2칸, 뒤 1칸) 두 칸은 비우고 나머지 33칸은 대형 보일러 외벽. 제어기가 40틱마다 (외벽이 부서지거나 제어기 옆이 바뀌면 다음 틱에) 모양을 확인하고, 빈손 우클릭은 바로 확인해서 상태 또는 첫 틀린 칸(좌표 · 지금 있는 블록)을 알려 줌. 모양이 맞으면 틱당 증기 24 = 보일러 6배 (설정 `bigBoiler.steamPerTick`), 연료는 5대 몫 (연소 틱이 틱마다 5씩 줄어 석탄 하나에 증기 7680, 보일러는 6400), 물 48000 · 증기 6000 · 연료 칸 4. 보일러 코드를 물려받는다 (`BoilerBlockEntity`에 용량 · 틱당 증기 · 연소 · 내보내기 훅을 열어 둠). 물: 물 양동이 우클릭, 제어기 옆의 물 원천 · 펌프 · 물 탱크 (외벽은 물을 받지 않음). 증기는 제어기와 **모든 외벽에 붙은 파이프 · 기계**로 나감 (`SteamOutlet`가 여러 시작 칸에서 파이프망을 찾음). 모양이 서면 외벽 무늬가 달아오른 띠로 바뀌고, 타는 동안 제어기가 불 켜진 모습 + 꼭대기에서 김. 비교기 = 증기 저장률, 계기판도 붙음 |
| I2 | 용광로 탑 (다중 블록) | 3x3 · 높이 3 내열 벽돌 외벽 + 제어기. 고압 증기로만. 화로 · 합금로 레시피를 한 번에 8개 처리 |
| I3 | 광석 3 · 4배 | 세척기(물을 탱크 · 펌프에서): 원석 → 정제 가루 3 (+희귀 가루 10%). 고압 정련기(고압 증기): 원석 → 정제 가루 4. 정제 가루 → 화로에서 주괴 |
| I4 | 렌치 · 면 설정 | 렌치: 블록 우클릭 = 돌리기, 웅크리고 우클릭 = 모드 기계를 바로 아이템으로(내용물 보존). 기계 면 설정: 면마다 넣기 / 빼기 / 막기 (렌치로 면을 눌러 바꿈) |
| I5 | 증기 기관차 · 화물 열차 · **구현** | 기관차(수레 + 보일러 모습)는 화로 수레처럼 스스로 밀고 가되 최고 속도 0.34블록/틱 (화로 수레 0.2, 설정 `locomotive.maxSpeed`). 연료 칸 하나 (석탄 · 숯 3600틱, 석탄 가루 1800틱, 한 묶음까지)를 먼저 태우고, 없으면 증기 통에서 받은 증기(4000까지)를 틱당 2 씀. 우클릭: 연료 · 증기 통이면 넣고 출발, 빈손이면 출발 / 멈춤 + 상태. 출발 방향은 첫 칸 반대쪽 (칸이 없으면 누른 사람 반대쪽). 칸 잇기: **연결 고리**(철 주괴 + 철 조각)를 들고 (화물칸 · 기관차는 웅크리고 빈손으로도) 수레를 누르면 3칸 안 가장 가까운 열차 꼬리에 붙고, 이어진 칸을 누르면 그 칸부터 뒤가 떨어진다. 칸 목록(UUID)은 기관차가 들고 칸마다 앞 칸 속도 + 간격 차(1.6칸 기준) x 0.4로 속도를 맞춤. 아무 수레나 칸이 된다 (보통 수레에 타고 갈 수 있음), 최대 16칸, 6칸 넘게 벌어지면 끊어짐. 화물칸 = 27칸 (통을 실은 수레). **적재 · 하역 역**(9칸, 깔때기 가능): 옆 한 칸(대각선 포함) 레일의 상자 달린 수레와 2틱마다 8개씩 (설정 `cargoStation.itemsPerTransfer`) 주고받음. 우클릭 = 적재 ↔ 하역, 웅크리고 빈손 = 창고 열기, 비교기 = 찬 정도. 덤: **꺼진 동력 레일 = 정거장** — 기관차가 그 위에서 연료를 아끼며 서 있다가 레일에 신호가 들어오면 다시 간다 (새 블록 없이) |
