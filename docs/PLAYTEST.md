# 싱글 실테스트

M1 → M2 → M3를 혼자 한 바퀴 돌며 손맛 · 난이도 · 바닐라와 이어지는 느낌을 본다.
자동 검사(GameTest 301개)가 못 보는 것: 보스 패턴을 실제로 피할 수 있나, 재미있나, 길을 잃지 않나.

## 띄우기

```bash
./gradlew runPlaytest
```

- 개발용 클라이언트가 `Tester`라는 이름으로 뜬다. 월드는 `run/playtest/saves/`에 남아서 다음에 이어서 할 수 있다 (자동 검사 폴더처럼 지워지지 않음).
- 편의 모드(Sodium · JEI · 미니맵 · 시체 등)까지 같이: 먼저 `python tools/make_mrpack.py build/libs/sanupcraft-0.1.0.jar 0.1.0 --download build/packmods`, 그다음
  `./gradlew runPlaytest --no-configuration-cache -PpackMods=<레포 절대 경로>/build/packmods/all`
- 친구들과 같은 환경(실제 설치)으로 보려면 릴리스의 `.mrpack`을 Modrinth App · Prism Launcher로 깐다.

## 두 가지 방법

1. **처음부터 (권장, 1회)**: 서바이벌 월드를 새로 만들어 바닐라처럼 시작. 막히면 발전 과제(L) → "산업크래프트" 탭이 다음 할 일을 알려 준다.
2. **단계 건너뛰기**: 치트 허용 월드에서 `/sanupcraft playtest <단계>`. 그 단계에 필요한 장비 · 재료를 받고, 네더 · 엔드 단계는 그 차원의 흑요석 발판으로 간다.

## 체크리스트

결과는 레포 이슈로 남긴다 (한 항목 = 한 이슈, 제목 앞에 `[실테스트]`).

### 오버월드 (M1) · 공장 개편 뒤
- [ ] 분쇄기를 만들 이유가 느껴지나 (가루 2배 + 부산물, 조약돌 · 자갈 → 자원, **강철에 석탄 가루가 필요**)
- [ ] 합금로: 철가루 2 + 석탄 가루 2 → 강철. 강철이 "바닐라에 없는 가치 있는 재료"로 느껴지나
- [ ] 강철 해머 · 굴삭 삽(3x3)이 공장을 지을 보상으로 충분한가
- [ ] 기계 화면에서 무엇이 어디 들어가는지 보이나 (재료 · 연료 · 결과 · 부산물). 빈 칸에 마우스를 올리면 칸 설명이, 불꽃 칸에는 증기가 뜨나
- [ ] 기계 · 장비 아이템 툴팁(쓰임새)이 읽을 만하고 겹치지 않나
- [ ] 기계 업그레이드 (`factory` 꾸러미): 기계 화면 왼쪽 2칸에 업그레이드만 들어가고 Shift 클릭으로도 들어가나 / 속도 2개면 확실히 빨라지나 (증기 · 연료도 그만큼 더 씀) / 효율이면 석탄 하나로 더 오래 도나 / 두 배로 가루가 가끔 하나 더 나오나 / 깔때기 · 벨트가 업그레이드를 넣거나 빼 가지 않나
- [ ] 업그레이드 값: 속도(핵 조각) · 두 배(파수꾼의 심장)가 재료 값을 하나, 효율(철판 + 레드스톤)이 너무 싸지 않나
- [ ] (편의 모드 켜고) JEI에서 철판 · 강철 · 가루를 눌렀을 때 압착기 · 합금로 · 분쇄기 화면이 뜨나, 부산물 확률 · 처리 시간이 보이나
- [ ] 조약돌 → 철 너겟 10%가 많은가 (조약돌 생성기로 철이 너무 쉽게 나오면 낮추기)
- [ ] 해머 3x3 처리량 (속도 60%여도 9칸이라 5.4배): 곡괭이가 무의미해지나
- [ ] 분쇄기 → 합금로 → 압착기 → 조립대 한 줄 짓는 데 걸린 시간: ____분 (목표 30~40)
- [ ] 강철 없이 녹슨 수호자에게 지는가 (녹 공격 1.5배 + 구속)
- [ ] 돌진 · 내려찍기 예고가 보이고 피할 만한가
- [ ] 강철 갑옷이 다이아를 대신하지 않는 느낌인가 (방어력은 철과 같음)

### 증기 · 자동화 (M2)
- [ ] 보일러 상태(빈손 우클릭)가 이해되나 / 물 원천 옆에 두면 물이 계속 차는 게 보이나
- [ ] 파이프 모양이 기계 쪽으로 이어지나 / 증기로 도는 기계에 불이 켜지나
- [ ] 벨트 방향(바라보는 쪽으로 나름)이 직관적인가 / 깔때기 → 벨트 → 상자가 막힘 없이 가나
- [ ] 굴착기 쓰레기 버림(기본 켜짐): 위 상자에 원석 · 광물만 오나 / 웅크리고 빈손 우클릭으로 끄면 돌도 오나 / 버리는 목록에 아쉬운 블록이 있나
- [ ] 증기 굴착기 위 상자에서 원석 · 조약돌만 골라 분쇄기로 보낼 수 있나 / 캐는 속도(4틱에 한 블록)가 적당한가 / 철 곡괭이로 못 캐는 흑요석이 남는 게 이해되나
- [ ] 벨트 분류기: 벨트 줄 가운데에 놓고 필터(우클릭, 아이템을 들고 칸 클릭 = 견본)에 철 주괴를 넣으면 철 주괴만 왼쪽, 나머지는 앞으로 가나 / 왼쪽 · 앞 출구가 상자 · 기계 · 다음 벨트일 때 다 이어지나 / 출구가 막히면 아이템이 기다렸다 길이 열리면 나가나 (사라지는 일 없나)
- [ ] 원석 표지(필터 칸에 놓음): 굴착기 위 상자 → 깔때기 → 벨트 → 분류기에서 원석 · 광석만 분쇄기 쪽(왼쪽)으로 빠지고 돌 · 흙은 앞으로 가나 / 분류기 한 칸이 줄 속도(4틱에 한 덩어리)를 따라가나
- [ ] 필터 깔때기: 바닐라 깔때기처럼 놓이고(옆구리가 출구) 필터에 맞는 것만 지나가나 / 필터가 비면 다 지나가는 게 자연스러운가 / 레드스톤 잠금이 되나 / 필터 화면(칸 클릭 · Shift 클릭)이 직관적인가
- [ ] 증기 충전대(파이프에 잇고 증기 통 · 부츠를 들고 우클릭으로 올림): 통이 0 → 1000까지 차오르나 (틱당 20) / 빈손 우클릭으로 꺼내지나 / 깔때기로 넣기(빈 칸) · 뽑기(가득 찼을 때)가 되나 / 막대(아이템 아래 하늘색 줄)와 툴팁의 "증기 n / 1000"이 맞나
- [ ] 리벳총 (`boss1` 꾸러미로 바로): 우클릭으로 쏘고, 리벳 · 증기가 줄고, 쿨다운 0.5초가 느껴지나 / 리벳이 없거나 증기가 없으면 짧은 안내가 뜨나 / 피해 6이 보스 앞에서 쓸 만한가 (너무 세거나 약한가) / 탄이 날아가는 모습이 보이나
- [ ] 증기 부츠: 점프 중 웅크리면 돌진하나 (증기 40, 쿨다운 1초) / 땅에서 웅크리면 안 나가나 / 높은 데서 떨어질 때 피해가 절반이고 증기가 줄어드나 / 증기가 0이면 일반 낙하 피해 / 돌진이 절벽을 건너는 데 너무 세지 않나
- [ ] 벨트 끝 기계에 석탄은 연료로, 원석은 재료로 들어가나 / 깔때기가 흙 같은 엉뚱한 것은 안 받나
- [ ] 펌프 (`steam` 꾸러미): 물 위에 놓고 증기 파이프를 이으면 1초에 원천 하나씩 빨아 옆 탱크가 차나 (빈손 우클릭: 유체 · 증기 · 힌트) / 무한 물에서는 계속 퍼 올리나 / 옆에 보일러를 두면 물 없는 보일러가 펌프 물로 도나
- [ ] 탱크: 물 · 용암 양동이로 붓고 빈 양동이로 퍼 내나 / 다른 유체를 부으면 안내가 뜨나 / 비교기 신호가 찬 정도를 따라가나 / 부순 탱크 툴팁에 내용이 남고 다시 놓으면 그대로인가 / 물 탱크 옆 보일러가 물을 끌어가나
- [ ] 보일러가 증기를 안 쓸 때 연료를 아끼나 / 힌트(물 없음 · 연료 없음 · 증기 가득)가 맞나
- [ ] 보스 1을 여러 번 잡는 게 지루하지 않은가 (핵 필요량은 ROADMAP "핵 약 8개")
- [ ] 보스를 잡으면 핵 · 심장이 바닥이 아니라 인벤토리로 들어오고 채팅에 "처치 보상"이 뜨나 (멀티: 여러 명이 각자 받나, 체력 배율이 맞나)

- [ ] 증기 분출(앞 부채꼴) · 화염 장판(바닥 고리) · 도약 내려찍기를 혼자 피할 수 있나 (분출은 방향이 잠기고 예고선이 보이나)
- [ ] 방패로 막으면 패턴 타격이 방패를 깨고 들어오나
- [ ] **필수** 기둥 위에서 활로만 잡을 수 있나 (잡히면 반격 패턴이 필요)
- [ ] **필수** 방치된 보스(멀리 두고 떠남) 때문에 제단이 계속 "근처에 이미 보스가 있다"가 되는 일이 있나
- [ ] 천장이 낮은 곳 · 평화로움에서 소환석이 쓰이지 않고 안내 문구가 뜨나
- [ ] `home` 단계로 오버월드에 돌아와 파수꾼 소환석을 쓰면 "너무 차갑다"가 뜨나
- [ ] 심장 제련로: 고대 잔해 1 → 네더라이트 파편 2, 블레이즈 막대 1 → 가루 4
- [ ] 네더라이트 장비를 만들고 싶어지나 (내열 = 다이아 수준이라 네더라이트가 위)

### 네더 전초기지 (M4) — `outpost`
- [ ] 용암 원천 옆에 지열 분출구를 두면 증기가 나오나 (빈손 우클릭: 용암 몇 곳 · 틱당 증기) / 오버월드에 두면 "너무 차갑다"
- [ ] 분출구 → 파이프 → 굴착기 · 심장 제련로가 돌아가나. 8 증기/틱이 너무 센가
- [ ] 굴착기에 내열 드릴을 끼우고(들고 우클릭) 네더 깊은 곳에서 돌리면 고대 잔해가 올라오나. 쓰레기 버림이 네더랙 · 현무암 · 블랙스톤을 버리나
- [ ] 위 상자 → 깔때기 → 엔더 송신기(주황) → 오버월드 수신기(주황)로 잔해 · 석영 · 금이 넘어가나
- [ ] 엔더 닻에 튀긴 후렴과를 넣고 오버월드로 돌아가도 네더 굴착기가 계속 도나 (수신기에 계속 쌓이나)
- [ ] 분쇄기에 네더 석영 광석 · 네더 금광석 · 발광석 · 마그마 블록을 넣으면 나오나 (JEI에 보이나)
- [ ] 펌프로 용암을 탱크에 모아(1양동이 이상) 분출구 옆에 두면 용암 원천 하나로 치나 (탱크 용암은 줄지 않는다) / 이게 용암 호수 옆을 찾아다닐 이유를 없애 버리지 않나

### 네더 심화 2 (M5) — `nether2`
- [ ] 영혼 흙 위에 영혼 화로를 두고 블레이즈 가루를 넣으면 불이 붙나 (빈손 우클릭: 고압 증기 · 가루 · 힌트) / 돌 위에 두면 "영혼 모래 · 영혼 흙 위에 두어야 탄다"
- [ ] 화로 → 고압 파이프 → 정밀 조립기: 강철판 + 금박 석영 → 정밀 부품이 나오나 (15초) / 정밀 조립기 화면에 연료 칸이 없나 / 업그레이드가 들어가나
- [ ] 고압 파이프가 보통 기계 · 보통 증기 파이프에 안 이어지고, 보통 증기 파이프가 정밀 조립기에 안 이어지나 (모양으로 보이나, 헷갈리지 않나)
- [ ] 화로 → 고압 파이프 → 증기 터빈 → 보통 증기 파이프 → 분쇄기가 도나 (터빈 빈손 우클릭: 고압 · 배율 · 내보낼 증기) / 계기판을 화로 · 터빈에 붙이면 읽히나
- [ ] 블레이즈 가루 1 = 고압 400 → 터빈으로 보통 1200: 보일러(석탄 1 = 보통 1600)와 견줘 수지가 맞나
- [ ] 금 분배기(금괴를 들고 우클릭)를 피글린 근처에 두면 3초마다 금괴를 던지고 피글린이 받아 교역하나 / 이미 금을 살펴보는 피글린 · 아기에게는 안 던지나 / 6칸이 적당한가
- [ ] 교역 수집판이 피글린이 떨군 교역품을 빨아들이나 (반경 3) / 분배기가 막 던진 금괴는 바로 안 먹고 기다리나 / 깔때기로 빠지나
- [ ] 잔해 탐지기 (가득 찬 것): 네더 깊은 곳(Y 8~22)에서 우클릭하면 방향(8방위) · 거리 · 위아래가 액션바에 뜨고 입자 줄이 그쪽을 가리키나 / 없으면 안내 / 증기 300 = 15번이 적당한가 / 충전대에서 채워지나
- [ ] 용암 증기선: 용암 바다에 놓이고(들고 우클릭) 타서 노를 저으면 물에서처럼 나아가나 / 출렁이거나 가라앉지 않나 / 타고 있는 동안 불이 안 붙나 (화염 저항) / 부수면 아이템이 용암에 타지 않나 / 물에서도 보통 배처럼 되나
- [ ] 버려진 용광로 (`/locate structure sanupcraft:abandoned_furnace`, 네더 황무지 · 현무암 삼각주): 바닥에 제대로 놓여 보이나 (허공 · 묻힘 없음), 제단 · 꺼진 심장 제련로 · 상자가 있나, 발전 과제 "식어 버린 용광로"가 뜨나
- [ ] 버려진 용광로의 심장 제련로를 캐 가면 공짜 제련로가 되는데 괜찮은가 (부서진 모습만 낼지)

### 엔드 최종 (M6) — `end2`
- [ ] 발판에 제단을 놓고 거상 소환석: 거상이 깨어나며 수정 넷이 떠오르고 빛줄기가 거상으로 이어지나 / 중앙 섬(원점 500칸 안) · 오버월드에서는 안내만 뜨고 소환석이 안 줄어드나
- [ ] 수정이 있는 동안 거상을 때리면 "수정을 먼저" 안내 · 피해 없음 / 리벳총 · 활로 수정이 깨지나 (리벳 4발) / 근접으로 닿는 높이인가 / 절반 아래에서 다시 넷이 뜨나
- [ ] 셜커 탄 일제 사격이 공중 부양을 걸어 공허 근처에서 위험한가 (너무 가혹하지 않나) / 끌어당기기 예고(좁아지는 보라 고리 · 소리)를 보고 피할 수 있나
- [ ] 거상을 잡으면 기여자마다 공허 핵 · 보스 기록판에 남나 / 체력 600(혼자)이 적당한가
- [ ] 공허 응축기를 발판 가장자리 바깥(아래가 공허)에 매달면 불이 들어오고 고압 증기가 나오나 (빈손 우클릭) / 발판 위에 놓으면 "아래가 공허가 아니다" / 고압 파이프 → 터빈 → 증기 파이프 → 후렴 수확기가 도나
- [ ] 정밀 조립기: 네더라이트 장비 + 공허 핵 → 공허 장비 (30초) / 공허 한 벌을 입고 발판에서 공허로 뛰어내리면 발판으로 올라오고 느린 낙하 / 5분 안에 다시 떨어지면 안 구해 주나
- [ ] 엔드 돌에 후렴 꽃을 심어 다 자라게 두면 (뼛가루 안 됨, 기다려야 함) 수확기가 맨 아래만 남기고 거두고 새 꽃을 심나 / 후렴과가 9칸 · 아래 깔때기로 나오나 / 분쇄기: 튀긴 후렴과 4 → 엔더 진주
- [ ] 차원 창고 둘에 같은 염료: 한쪽에 넣은 것이 다른 쪽에 보이나 / 오버월드에 하나 더 놓아도 같은가 / 웅크리고 빈손 우클릭으로 채널이 잠기나 / 부숴도 내용이 남나 / 깔때기로 넣고 빼지나
- [ ] 겉날개로 날며 증기 통 우클릭: 폭죽처럼 가속되고 증기 100이 주나 / 땅에서는 아무 일 없나
- [ ] 숨결 수집기에 유리병을 넣고 엔더 드래곤의 숨결 구름 근처(8칸)에 두면 1초마다 채워지나 (드래곤과 싸울 때만 볼 수 있음)
- [ ] 버려진 정거장 (`/locate structure sanupcraft:abandoned_station`, 바깥 섬): 섬 위에 다리로 서 있나 (공허에 떠 있지 않나) · 사다리로 오르나 · 상자 · 제단, 발전 과제 "멈춘 정거장"

### 엔드 (M3)
- [ ] 엔더 송신기 · 수신기에 같은 염료를 쓰면 채널이 맞춰지나 (송신기 빈손 우클릭: 연결된 수신기 수 / 수신기는 웅크리고 빈손 우클릭: 채널)
- [ ] 송신기 제작에 파수꾼의 심장이 들어가는 게 부담스럽지 않나
- [ ] 네더(또는 엔드)의 송신기 → 오버월드 수신기로 아이템이 넘어가나
- [ ] 채널이 다르면 송신기가 아이템을 받지 않나
- [ ] 잠금: 웅크리고 빈손 우클릭으로 잠그면 안내가 뜨나 (혼자서는 남이 못 여는 건 확인 못 함 — 멀티에서)

### 월드 탐험
- [ ] 평원 · 숲에서 녹슨 사당을 만났나 (`/locate structure sanupcraft:rusted_shrine`), 상자에 소환석이 있나, 발전 과제 "옛 제단"이 뜨나
- [ ] 네더 요새 상자에서 파수꾼 소환석 · 핵 조각이 나오나 (20% · 30%)
- [ ] 드릴 없이 굴착기를 돌리다 드릴을 끼우면, 지나간 층의 흑요석을 다시 캐나

### 생산 · 장비 (M9a) — `production`
- [ ] 작물 수확기: 밭(경작지에 밀 · 당근을 심고 뼛가루로 키움)을 보고 놓아 파이프를 이으면, 다 자란 것만 거두고 씨앗으로 다시 심나 / 앞 9x9가 한눈에 이해되나 (수확기와 같은 높이를 훑는 것) / 덜 자란 것은 그대로 두나
- [ ] 수확기: 아래 상자 · 깔때기로 거둔 것이 나가나 / 상자가 꽉 차면 멈추고 상태(웅크리고 빈손 우클릭)에 "가득"이 뜨나 / 증기가 없으면 멈추나 / 증기 3이 적당한가
- [ ] 벌목기: 나무 앞에 놓고 파이프를 이으면 원목 · 잎을 위에서부터 베나 / 묘목을 칸에 넣어 두면 다시 심나 (잎에서 나온 묘목도) / 통나무집 · 쌓아 둔 원목은 안전한가 / 큰 나무(참나무 큰 것 · 정글)에서 증기 800으로 충분한가
- [ ] 증기 드릴: 충전된 것을 들고 돌 · 흙을 캘 때 속도(다이아 수준)가 괜찮나 / 웅크리고 우클릭으로 1x1 ↔ 3x3 모드가 바뀌고 툴팁 · 안내가 맞나 / 3x3이 바라본 면 기준 평평하게 파지나 / 증기가 떨어지면 맨손처럼 느려지는 게 이해되나 (내구도가 없어서 증기 경제가 곧 내구도)
- [ ] 전기톱: 원목 하나를 캐면 나무가 통째로 쓰러지나 / 잎까지 베고 드롭이 자연스럽나 / 웅크리고 캐면 한 개만 / 증기 소모(원목 10 · 잎 2)가 적당한가 / 큰 나무 하나에 증기 통 하나 가까이 드나
- [ ] 증기 제트팩: 가슴 칸에 입고 점프 키를 누르고 있으면 오르나 (초당 약 8칸) / 반응이 늦거나 끊기지 않나 / 놓으면 떨어지고 낙하 피해가 없나 (떠 있는 동안 낙하 거리 초기화) / 증기가 없으면 그냥 떨어지나 / 서버에서 오래 떠 있어도 "날기"로 쫓겨나지 않나 (멀티에서)
- [ ] 충전대로 제트팩 · 드릴 · 전기톱을 채울 수 있나 (제트팩 3000 / 틱당 20이면 150틱)

### 산업 규모 (M8) — `industry`
- [ ] 외벽 33 + 제어기로 3x3 · 높이 4를 쌓으면 (가운데 2 · 3층 비움) 외벽 무늬가 바뀌고, 하나 틀리게 쌓으면 제어기 빈손 우클릭이 틀린 칸 좌표를 알려 주나
- [ ] 모양이 선 대형 보일러가 물 · 석탄으로 증기를 내고, 제어기가 아닌 외벽에 붙인 파이프로도 기계가 도나. 외벽 하나를 부수면 바로 멈추나
- [ ] 기관차를 레일에 두고 석탄(또는 증기 통)을 넣으면 출발하고, 빈손 우클릭으로 서나. 화로 수레보다 빠른 게 느껴지나
- [ ] 연결 고리로 화물칸 2개를 이으면 간격을 두고 따라오나, 굽은 길 · 비탈에서 끊어지거나 엉키지 않나
- [ ] 꺼진 동력 레일에서 열차가 서고, 레버로 신호를 주면 다시 가나. 그 옆 역(적재 · 하역)에서 아이템이 옮겨지나
- [ ] 다시 접속한 뒤에도 연결이 남아 있나

### 보관 · 제작 (M7) — `storage`
- [ ] 서랍 앞면 우클릭으로 넣기, 빨리 두 번 우클릭으로 인벤토리의 같은 것 전부, 좌클릭 하나 · 웅크리고 좌클릭 한 더미가 되나 / 앞면에서는 안 부서지고 옆에서 캐지나 / 앞면에 아이템 그림 · 개수(1.2k)가 보이나
- [ ] 서랍 업그레이드: 용량 ×2 (2개까지), 넘침 버림 / 웅크리고 빈손 우클릭으로 빠지나 / 부순 서랍을 다시 놓으면 내용물이 그대로인가 (툴팁에 보이나)
- [ ] 깔때기로 서랍에 넣고 아래 깔때기로 빼지나 / 벨트 끝에 서랍을 두면 받나
- [ ] 창고 관으로 상자 · 서랍을 잇고 단말(증기 필요)을 열면 전부 한 화면에 보이나 / 검색(이름 · ID · @모드) · 정렬(# / A) · 굴리기가 되나
- [ ] 단말 목록 클릭: 왼쪽 한 더미 · 오른쪽 반 더미 · Shift 인벤토리로 / 들고 누르면 넣기 / 인벤토리 Shift 클릭으로 넣으면 같은 것이 든 상자 · 서랍부터 채우나
- [ ] 단말 증기: 증기가 없으면 "증기가 없어" 안내 / 열어 둔 동안 틱당 1이 부담스럽지 않나 / 웅크리고 빈손 우클릭 잠금
- [ ] 제작 단말: 3x3로 만들면 빈 칸이 네트워크에서 다시 차나 / Shift로 결과를 누르면 재료가 떨어질 때까지 만드나 / (JEI) 레시피의 + 버튼으로 재료가 놓이나 / 닫으면 칸의 것이 네트워크로 돌아가나
- [ ] 자동 제작대: 견본 3x3 (아이템을 들고 칸 클릭, 손의 것은 그대로) → 가운데에 결과가 보이나 / 재료 칸에 넣고 증기를 주면 만들어지나 (한 번에 20) / 깔때기로 재료를 넣으면 같은 재료 칸에 고르게 들어가나
- [ ] 재고 유지기(파수꾼의 심장): 관에 잇고 옆에 자동 제작대를 두고 "판자 64개 유지" → 원목을 넣어 만들고 결과를 창고로 거두나 / 옆에 분쇄기를 두고 "철가루 유지" → 원석 철을 넣나 (연료는 따로) / 상태 글(넉넉함 · 만드는 중 · 재료가 모자람)이 맞나
- [ ] 휴대 단말: 단말에 우클릭으로 연결, 들고 우클릭으로 열림 / 64칸 밖 · 다른 차원이면 안내 / 셜커 휴대 단말은 네더 · 엔드에서도 열리나 (단말 청크를 엔더 닻으로 붙잡아 두기)
- [ ] 큰 창고(상자 20개 이상)에서 단말을 열 때 끊김이 없나

- [ ] `/sanupcraft team create <이름>` 후 이름표 · 채팅에 [이름]과 색이 붙나 / 다른 사람이 `join <이름>`으로 들어오면 같은 색이 되나 / 한글 이름도 되나
- [ ] `lock`으로 잠그면 새 사람이 못 들어오나 / 주인이 나가면 다음 사람이 주인이 되나 / `list`가 읽기 좋은가

- [ ] 제단에서 소환한 수호자를 잡으면 보스 기록판에 시간 · 이름이 뜨나 (우클릭), 1위면 서버 전체에 알림이 가나
- [ ] 공용 목표판: 강철 주괴를 들고 우클릭하면 들어가고, 깔때기로도 들어가나 / 웅크리고 우클릭하면 기여자가 보이나 / 다 채우면 알림 · 발전 과제 · 보상 상자가 나오나 (`goal set`으로 작은 목표를 주면 빨리 본다)
- [ ] 처음 접속하면 설명서를 받나 (새 월드), 우클릭으로 책 화면이 열리나, 쪽 글이 잘리거나 넘치지 않나 / 책 + 철판으로 다시 만들어지나

### 생산 2 (M9b) — `production2`
- [ ] 보일러 + 파이프로 몹 분쇄기에 증기를 이은 뒤 좀비 소환 알을 위 칸 근처에 쓰면, 위 칸에 선 좀비가 1초마다 맞아 죽나 (5초 안팎) / 증기가 없으면 안 베나
- [ ] 죽을 때 경험치 구슬이 나오고, 옆에 붙인 경험치 탱크로 빨려 들어가나 (탱크가 없으면 분쇄기 안에, 빈손 우클릭하면 받아지나)
- [ ] 플레이어 · 길들인 동물 · 이름표 붙은 몹 · 주민은 위 칸에 서 있어도 안 맞나 / 베인 몹이 밀려나지 않고 제자리에서 맞나
- [ ] 분쇄기 위 칸을 막힌 구덩이로 만들어 몹을 가두고, 아래쪽 깔때기로 전리품을 받는 농장이 지을 만한가 (몹이 위 칸에 서게 하는 법이 번거롭지 않나)
- [ ] 경험치 탱크 빈손 우클릭 = 레벨 하나 몫, 웅크리고 = 전부 / 유리병 우클릭 = 경험의 병 (10점, 값이 맞나) / 비교기가 찬 정도를 읽나 / 부숴도 내용이 아이템에 남나
- [ ] 배낭 우클릭으로 27칸이 열리고, 닫았다 열어도 내용이 그대로인가 / 배낭을 배낭에 넣을 수 없나 / 창이 열린 채 그 배낭을 집거나 옮길 수 없나
- [ ] 배낭 + 강철판 4개(작업대)로 강철 배낭이 되고 내용이 그대로 넘어오나, 54칸 창이 화면에 맞나 / 배낭을 떨어뜨렸다 주워도 내용이 있나 / 툴팁에 내용 목록이 보이나

### 강화 소환석 (C3) — `tiers`
- [ ] 작업대에 수호자 소환석 + 핵 조각 4개(모양 상관없음)를 놓으면 이름에 "+1"이 붙은 소환석이 나오나 / 파수꾼 소환석은 심장 1개로 되나 / +3에서 더 안 올라가나 / 재료 수가 틀리면 안 되나
- [ ] 강화 소환석 툴팁에 체력 · 피해 · 보상 증가가 읽기 좋게 나오나, 단계가 다른 소환석이 따로 쌓이나 (JEI · 레시피 책에는 이 레시피가 안 보인다 — 툴팁 안내로 충분한가)
- [ ] 제단에 +1 · +2 · +3을 차례로 써서 보스가 눈에 띄게 세지나 (체력 +50% · 피해 +25%씩) / 보스 바 이름에 "+N"이 붙나 / 소환 때 채팅에 단계 안내가 뜨나
- [ ] +3이 사람이 감당할 만한가 (강철 · 내열 한 벌, 여러 명) — 체력 2.5배 + 인원 배율(최대 3배) = 최대 7.5배가 너무 단단하지 않나, 피해 1.75배가 너무 아프지 않나 (`bossTier` 설정으로 조절)
- [ ] 잡으면 기여자 각자 핵 · 심장을 단계 + 1개 받고 기계 업그레이드(속도 · 효율 · 두 배 중 하나)를 받나 / 보스 기록판에 "강화 N단계"가 뜨나
- [ ] +3을 부르면 발전 과제 "더 강한 적"이 뜨나
- [ ] 거상 소환석 + 공허 핵 1개로 강화되나 / 엔드 제단(원점 500칸 밖)에서 +2 거상의 보스 바에 "+2"가 붙고, 셜커 탄이 더 아프나 (4 → 6) / 잡으면 공허 핵 3개 + 업그레이드
- [ ] 여러 명 + 강화로 체력이 1024를 넘는 보스 (수호자 5명 +3 = 2250 등): 체력 칸은 1024에서 멈추지만 그만큼 덜 깎여서, 실제로 원래 체력만큼 버티나 (보스 바가 너무 느리게 줄어 답답하지 않나)

### 산업 규모 2 (M8 묶음 B) — `industry2`
- [ ] 내열 벽돌 23 + 제어기로 3x3 · 높이 3을 쌓으면 (가운데 기둥 세 칸 비움) 벽돌 줄눈이 달아오르나, 하나 틀리면 제어기 빈손 우클릭이 틀린 칸을 알려 주나
- [ ] 영혼 화로 → 고압 파이프를 제어기가 아닌 벽돌에 붙여도 고압 증기가 들어가나 (웅크리고 빈손 우클릭 = 상태) / 계기판이 제어기를 읽나
- [ ] 제어기 빈손 우클릭으로 9x2 화면이 열리고, 윗줄에 철가루 · 원석 등을 넣으면 한 번에 8개씩 (화로 한 개 시간에) 아랫줄로 구워지나 / 철가루 + 석탄 가루가 같이 있으면 강철을 먼저 만드나
- [ ] 깔때기: 위 · 옆으로 재료(구울 수 있는 것만), 아래로 결과 / 비교기가 찬 정도를 읽나 / 벽돌 하나를 부수면 멈추나
- [ ] 세척기: 물 양동이 우클릭 · 옆 펌프 · 물 탱크로 물이 차고 화면 왼쪽 물 눈금이 오르나 / 원석 하나 → 정제 가루 3, 가끔 희귀 가루 / 물이 떨어지면 멈추나
- [ ] 고압 정련기: 고압 파이프로만 돌고 원석 하나 → 정제 가루 4 / 정제 가루가 화로 · 용광로 · 용광로 탑에서 주괴가 되나
- [ ] 희귀 가루 4 + 정밀 부품 → 두 배 업그레이드 (정밀 조립기)가 쓸 만한가, JEI에 세척기 · 고압 정련기 레시피가 보이나

### 렌치 · 면 설정 (M8 I4) — `wrench`
- [ ] 렌치(돌리기 모드)로 기계 · 벨트 · 깔때기 · 화로 · 계단을 우클릭하면 돌아가나 / 침대 · 문 · 큰 상자 · 돌은 "돌릴 수 없다"가 뜨나
- [ ] 허공에 우클릭하면 "모드: 면 설정"으로 바뀌고, 기계 면을 누르면 기본 → 넣기 → 빼기 → 둘 다 → 막기 순으로 바뀌며 액션바에 여섯 면이 보이나
- [ ] 위 면을 막기로 하면 위 깔때기가 못 넣나 / 위 면을 빼기로 하면 넣기는 막히고 아래 깔때기는 결과를 그대로 빼나 / 벨트가 닿은 면 설정을 따르나 (기본 면이면 예전처럼)
- [ ] 면 설정을 한 기계를 렌치로 돌리면 설정도 같이 도나 (앞 면 막기 → 돌려도 앞이 막힘)
- [ ] 웅크리고 렌치로 재료 · 결과 · 업그레이드가 든 분쇄기를 집으면 아무것도 안 쏟아지고, 다시 놓으면 그대로인가 (툴팁에 내용물)
- [ ] 엔더 수신기를 잠그고 다른 사람이 웅크리고 렌치 → "잠겨 있다" / 엔더 닻은 못 집나 / 바닐라 상자는 못 집나

### 효과음 · 입자 (M11 X2) — `factory` · `steam` · `boss1` · `boss2` · `nether2`
- [ ] 분쇄기 · 압착기 · 조립대 · 정밀 조립기 · 세척기가 도는 동안 몇 초에 한 번 작게 작동음이 나나, 자막(설정 → 자막 켜기)이 뜨나

- [ ] 굴착기가 파는 동안 돌 캐는 소리가 나나 / 기계 여러 대가 너무 시끄러우면 `sounds.machineVolume`을 낮춰 보기
- [ ] 수호자: 돌진 방향을 잠글 때 갈리는 예고음, 졸개 부르기 전 둘레 마법 입자, 체력 절반에서 으르렁 + 연기, 쓰러지는 소리가 나나
- [ ] 파수꾼: 증기 분출 방향을 잠글 때 숨 들이켜는 예고음, 체력 절반에서 으르렁 + 불꽃, 꺼지는 소리가 나나
